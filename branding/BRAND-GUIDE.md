# ORYVA by Sun — Brand Guide

**Product:** SUN-001 · **Tagline:** Identity. Trust. Protection.

## Approved direction

The original sunrise and mountain identity is the sole ORYVA brand direction. The sun arc connects ORYVA to SUN; mountain peaks convey resilience and trust; the four-point star conveys clarity. Do not substitute shield, keyhole or hexagonal logos.

## Usage

Use the panoramic asset above the README title. Preserve the tagline and `by Sun` attribution. Keep sufficient clear space around the icon and do not stretch artwork or recolor the sun arc. The icon is suitable for product UI at larger sizes; test legibility at favicon sizes before adopting it there.

## SUN canonical asset layout

The active README banner is `branding/assets/readme-banner-v1.svg` and its byte-identical archival copy is `branding/archive/originals/readme-banner-v1.svg`. This is an archival copy of the **approved SVG adaptation**, not a claim that the original raster concept board is available. The existing dark lockup is `branding/assets/lockup-dark.svg`; the existing app icon is `branding/assets/icons/app-icon.svg`. The alternative panoramic SVG is preserved under `branding/archive/intermediate/` as a nonproduction treatment.

All files were relocated using their existing Git blob SHAs, without artwork regeneration. **PNG variants, a transparent canonical raster symbol, light/mono lockups and favicon-size optical exports are not yet established**; those require separate owner-approved design/export work. Do not treat SVG file naming as proof of equivalent PNG assets.
